# Base human: set C4 (adult pass on C3 bases 1–3; Cloud dropped)

All three bases share these changes:
- **Face:** longer face with flatter cheek planes and a squared, defined chin. The mouth sits higher, with real chin length below it. The hairline is raised, so more face shows below the hair.
- **Shading:** the archer's soft side gradient is used on both faces and hair. Nothing uses the hard split.
- **Shoulders:** a plain linen shoulder mass (two rounded caps, front edge dipped at the centre) sits under each head, so the head is no longer the whole body.
- **Hands:** smaller and flatter, 22x18 (base 3's are 18x22).
- **Size:** each head still fits the hood footprint.

1. **Mop**: the chestnut mop is worn higher, with uneven lobes swept slightly right. There's a soft stubble shadow on the jaw, the ears show, the shoulders are broad, and both fists are up in front.
2. **Curtains**: the part is now off-centre (x≈92) and is a wide, soft gradient band instead of a sharp line. The curtains stop at the jaw, the left one narrower than the right. The face is long and narrow, the shoulders sloped, and the hands are stacked in a front grip.
3. **Egg + Bun**: the liked design is kept (bun back-left, side-swept wheat fringe, ears, hands at the flanks). The fringe sits higher, the face below it is longer, and the chin is squared. The hands now rest at the shoulder tips.

## Still weak
- **Shoulder colour:** the linen is a placeholder base colour. Classes will recolour it or cover it.
- **Mop's stubble:** it darkens the lower face as a whole more than it reads as stubble.
- **Curtains hands:** they sit well forward of the shoulders and look a little detached.
- **At 40px:** the shoulders make all three read more like "a person". Mop and Egg + Bun are still fairly round-headed, but the face length now helps.
